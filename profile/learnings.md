# Learnings

Why the profile says what it says. Newest at the bottom. One entry per
calibration or hand edit.

`voice.json` holds the numbers. This file holds the reasons, because in six
weeks nobody can argue with a bare number.

## Format

```
## YYYY-MM-DD - what changed

**Evidence:** which samples, how many words, what the measurement was.
**Rule it produces:** what --check does differently now.
**What I no longer believe:** the entry people skip, and the one that matters.
```

That last line is the one worth pausing on. A calibration that changes nothing
you previously believed usually means the samples told you nothing. If the
profile now says your spread is 14 and you had been editing toward 8, write
that down: you tightened every earlier draft in the wrong direction.
